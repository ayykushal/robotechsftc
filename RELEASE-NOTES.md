# v1.0.0 — October 20, 2026

First release of the new Robotechs website.

- Shared official logo, blue/white/grey theme, Outfit font, floating glass navigation, and responsive layouts.
- Twelve-member glass roster, original team photos, caption-free team gallery, and achievement links.
- 2025–26 engineering journal with nine milestones, original photo enlargement, and 2026–27 development notice.
- Eight archived events and two planned language-class demos, with detail pages.
- Tutorials, Onshape playlist, portfolio, code and CAD destinations.
- Instagram calls to action and canonical YouTube links.
- Privacy and terms pages, essential-only privacy notice, contact validation, and custom 404.
- Clean hosted URLs, indexing-ready public pages, original image files, and a domain-aware production build.

No analytics, password-protected dashboard, Facebook links, store, groups, old blogs, or 2024–25 pages are included.

## Verification

Static checks cover page headings, local links/anchors, images and enlargement targets, metadata, clean navigation, and absence of analytics collection. JavaScript syntax and meaningful contact-validation cases were checked. Earlier outbound-link checks returned successful responses for all ten external destinations. Core text/button contrast pairs passed contrast checks.

Canonical URLs and sitemap entries are generated using the real hosting origin during the production build. No invented live domain is included. Browser rendering and the eventual host’s HTTPS, rewrite, document permissions, and live performance must be checked for the chosen deployment. The contact action composes email and does not submit messages to a website server.
